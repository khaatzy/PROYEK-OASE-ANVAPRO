# OASE Cerita - Obrolan Aman Seputar Emosi 🌸

> Ruang tenang dan aman untuk melepaskan beban pikiran, memvalidasi setiap rasa, dan terhubung dengan sesama tanpa takut dihakimi.

---

## 🎨 Tema & Desain
- **Warna Dominan**: Heather Mauve (`#A14189`)
- **Palet Pendukung**: Soft Lavender Mist, Dusty Rose, Warm Off-White, Deep Plum text
- **Tipografi**: Plus Jakarta Sans
- **Ikon**: Lucide Icons

## 🚀 Fitur Utama
1. **Dashboard Sambutan**: Pesan penenang dan pengantar ruang aman emosi.
2. **Interactive Emotion Selector**: Pemilih suasana hati harian dengan respon empati otomatis.
3. **Mengenal OASE Cerita**: Penjelasan privasi penuh/anonim, ruang validasi empati, dan jurnal personal.
4. **Fitur Layanan**: Tulis Curhat (publik/privat), Komunitas Empatis, Peta Mood & Relaksasi.
5. **Modal Login**: Akses masuk untuk mulai bercerita.
6. **Hotline Krisis**: Jalur cepat kontak darurat kesehatan mental (119 ext 8).

## 🛠️ Menjalankan Proyek
Cukup buka berkas `index.html` langsung di browser Anda.
